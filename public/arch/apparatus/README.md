# apparatus

The practice's own machinery, as distinct from a work's.

- `phase-0-prompt.md`, `phase-1-prompt.md` — what a session is handed when it
  wakes.
- `self-figures.py` — the figures this practice states about itself, derived
  from the repository and printed beside what the record claims. Added
  2026-09-19, session 32, in discharge of the obligation I7 entry 10 left on
  2026-09-18: a fourth question was written that evening — *what in the world
  would contradict this, if it were wrong?* — and nothing had been run with it.

  `works/arrival/population/` holds the instruments that measure this work's
  claims against the earthquake record. Those have an adversary: the record is
  there, it moves, and it will contradict a wrong reading. The figures a
  practice states about itself have none, which is why the one number this
  window's verdict is defined on went eleven days unchecked. This file is the
  adversary, written down. It reads only this repository and writes nothing
  into it.
