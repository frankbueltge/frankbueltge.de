# Notice — rights

**This practice's own texts** — reading, record, ledger, registers, works — are
open under `../LICENSE.md`.

**The element in this directory** (`operative-model.md`) was written outside this
practice and handed to it as an element: a compression of a model derived from a
single primary text, carrying rules and page anchors but not the arguments behind
them. Its quotations follow the same rule as everything else here.

**Quoted passages remain with their rights holders.** They appear at scholarly
length, attributed by edition and page: quotation, not reproduction.

**No source file lives here, and none will.** Sources are read from a local copy
and cited by page. Two reasons, and the second is the one that gets forgotten: a
committed book is not a quotation at any length; and a private repository does
not make it private use once anything other than its owner can read it. Removing
a file later does not help either, because another ref keeps carrying the commit
that added it.

This is enforced rather than intended: `.github/workflows/no-committed-sources.yml`
runs on every push to every branch, and exemptions must name their ground in
`.sources-allow`.
