One maker's page, running live, left as made and right reading the same table with one column dealt out at random. The page's code is not touched. Every count, total and legend it computes from a single column comes out the same; only what holds between columns breaks. Below the pages, one relation the makers saw: how strongly a bridge's year of building goes with its lowest condition rating (Pearson's r, computed here from the table each page reads).
