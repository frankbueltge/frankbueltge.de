# Seventy-Seven Hours a Pixel

The record arrived as 114 grey values, so each pixel column stands for about 77 hours, and anything shorter than three days is gone. The work rebuilds that 19 × 6 picture out of its 1,464 hours. Each hour is one hairline, set exactly where it falls in time, because that is the one thing the file still knows. Which of the six bands an hour lands in is decided by lot, weighted by how grey its pixel is. Where it sat inside that band is not known at all, so the line runs the full height of the band rather than standing for a point. Below it is a 61-day ruler. Red marks show where the pixel columns start and stop, and none of them falls on a midnight, so the picture's grain never lines up with the days the record was taken in. I chose this form so the image shows how coarse the record is, rather than drawing a smooth curve the file can't support. The original is placed at its true size in the corner, to show how small it really is.
