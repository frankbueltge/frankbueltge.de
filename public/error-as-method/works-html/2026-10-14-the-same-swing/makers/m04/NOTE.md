# Forty Strings

The record reached me as 480 pixels, so each pixel column had swallowed about 36.6 hours of values, and inside a column the order of those hours is gone. The work does not hide that. It hangs forty vertical strings, one for each column, and threads each with its true share of the 1,464 hourly values: 36 or 37 beads, placed at evenly spaced quantiles of how dark that column is, so the beads bunch where the picture was darkest. The enlarged pixels sit faintly behind the strings, and the original image appears once at actual size. What you can still read is what the file still holds: how far each day and a half's values spread and where they sit, swelling and narrowing over the two months. The dot count is exact. The heights are an estimate, and their order within a string is unknown.
