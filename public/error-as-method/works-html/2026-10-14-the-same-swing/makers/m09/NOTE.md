# Forty Widths

The file promises one dot per value, but at 40 by 12 pixels the dots have merged: every column is a dark span covering half to nearly all of its height, so the record holds far more values than the picture has columns, and what survives is only how far each column reaches up and down. The work enlarges all 480 pixels exactly as found, grey tones and compression smudges included, separated into forty upright columns so they read as forty moments in sequence rather than as a picture. A thin red line traces where each column turns dark, top and bottom, and a row of red strokes underneath gives each column's span. I chose this because it shows only what the file actually holds, the reach of a swing too fast to resolve, and does not invent the individual values that the image has already lost.
