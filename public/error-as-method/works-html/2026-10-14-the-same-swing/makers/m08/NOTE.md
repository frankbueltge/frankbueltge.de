# Sixty-One Turns

The record turned out to repeat every 24 values almost exactly, so the work winds it into a spiral of 61 turns, twenty-four values to a turn, beginning at the centre; each value moves the line outward when it is larger and inward when it is smaller. Laid out flat the repetition was only a dense hatching; wound at its own period it turns into rings. The days with a large swing pull their ring off-centre, always towards the same side, and the quiet stretches lie as almost true circles, so the record's alternation between big and small swings shows up as rings crowding and spreading like growth rings in wood. The 1,464 dots sit on 24 spokes, which keeps the counting visible. I read the values back out of a small, compressed picture, so they are an estimate; that picture is set beside the spiral at its own scale so the source stays in view.
