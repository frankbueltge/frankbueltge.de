# 1,464 into 40

The record held one value for each of 1,464 hours, but the picture I was given is only 40 pixels wide, so each pixel column had to hold about 36.6 hours. Inside a column, the hours sit on top of each other: their order, the daily rhythm, any single reading can no longer be recovered. The work shows that loss directly instead of making up a curve to cover it. Along the bottom is a ruler with a tick for every hour and a longer tick at the start of each of the 61 days. From each tick, a hairline runs up and gathers with its neighbours into one of 40 narrow stems. Each stem feeds a column drawn from that column's 12 actual grey values, enlarged and softened only between neighbouring pixels. What remains readable is what the source still holds: how high and low each day and a half reached, and how that spread widens and narrows over the two months. I chose this form because the most true thing about this material is the gap between the hours that were measured and the pixels that reached me.
