# Somewhere in Here

The record arrived as a picture only 40 pixels wide, so each pixel column holds about 36.6 of its 1,464 hours, and inside a column nothing tells one hour from another. The work does not guess where any single value was. It gives each hour its own thin vertical thread and draws that thread at every height its column says the dots occupied, with darkness taken from the picture's own grey values. The 1,464 threads are set in four bands of 366 hours. Ticks above each band mark the 40 columns the record was squeezed into; ticks below mark the 61 midnights, which fall out of step with the columns. What shows is the one thing the picture still holds, the width and drift of the spread, as a series of 36.6-hour blocks. I chose this form so the image shows that loss plainly instead of covering it with a smooth line the file cannot support.
