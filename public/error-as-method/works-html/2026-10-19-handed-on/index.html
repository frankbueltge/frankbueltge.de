Handed On

Six lineages, one dataset (every Nobel Prize award, 1901–2026), four versions each. Every version shown here was made by a machine maker. Between two versions, the mark is what a blind coder saw change, from the two pictures alone: ■ schema (the form reorganised), ■ strike (something removed), ■ add (refined). Select any version to see it running, with its maker's note.

Plain hand-over: each next version by a new maker who sees only the last one, its picture and the notes. Test hand-over: the same, plus the working paper's I2 test after Simondon ("complication is not concretization") and leave to decline. Kept: the first maker, sent back with one sentence, "Make the next version of your work." Arms drawn by seed before any maker ran; predictions committed first (PREDICTIONS.md). Data: Nobel Prize API v2.1, api.nobelprize.org, CC0. Text and evidence: work.md, results.json, coder/, reports/.
