# Thirty-Six and a Half

The picture I was given is 40 pixels wide for 1,464 values, so about 36.6 values share each column and their heights survive only as 12 rows of ink. The form keeps both facts at once: every one of the 1,464 values gets its own hairline at its exact place in time, but no value gets a height — each hairline is shaded down its whole length by the ink of the column it falls in, so it stands across every height the picture still allows. Read from a distance it is the record's shape; read closely it is a row of measurements whose places are known and whose sizes are lost. I chose this because the only true thing I could draw at full resolution was the count and the order, and inventing 1,464 heights would have been a forgery of the data rather than a form for it.
