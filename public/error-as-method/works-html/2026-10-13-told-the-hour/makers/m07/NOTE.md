# Thirty-Seven to a Column

The picture I was given cannot hold 1,464 values: it is 40 squares wide, so each column of pixels had to swallow 36 or 37 of them, and all that survives is how grey each square turned. The work gives those values back only as much as the picture allows. The enlarged grid of greys stays faintly underneath, and in each of its 40 columns the 36 or 37 values are set down again as dots, spaced so that more of them fall where the column is darker. They sit in a single vertical line, because the picture no longer says in what order they came within the column. I chose this form so that the count is exact and the order and fine detail are visibly absent. The image shows the record and what was lost from it at once, rather than inventing a smooth line the file cannot support.
