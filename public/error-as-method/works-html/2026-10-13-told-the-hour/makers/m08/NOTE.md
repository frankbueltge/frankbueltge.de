# Thirty-Six and a Half Hours

The file holds 1,464 hourly values but only 480 pixels, so each pixel column swallows about 36.6 hours and each row an unknown twelfth of the range; the original dots cannot be got back. The work makes that loss the subject. It enlarges the 40 × 12 grid and gives every column back its exact share of hours (36 or 37), then sets those hours down as 1,464 dots, divided among the cells in proportion to how dark the JPEG left each one (largest-remainder rounding, so the faint compression smudges still claim the odd stray hour). Inside a cell the dots are spaced evenly, not placed, because where they really were inside it is exactly what the picture no longer knows. Under the grid a ruler of 1,464 hour ticks, with a longer one at every 24th, is bracketed column by column. You can see how many hours went into each pixel. Nothing is invented beyond the count. The form shows how much is still there and how coarsely it is filed.
