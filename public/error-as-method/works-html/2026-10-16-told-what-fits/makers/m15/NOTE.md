# The Long Exhale

The record's own rhythm is a 24-hour cycle (a frequency check on the picture puts it at exactly one cycle per day), so the work cuts the 1,464 values into 61 lines, one per day. Each line runs from hour 0 to hour 24, and each day hangs just below the day before it. Where a line rises, it covers the days above it. In a flat strip chart the daily swing and the slow weekly drift get mixed into one sawtooth. Stacked like this, they separate. The midday sag shows up as a valley running down the page, deepening from one day to the next. The days when the whole level suddenly jumps and the daily cycle nearly stops show up as heavier, almost straight lines that cut across that valley. I drew it as a still ink-on-paper stack of lines to stay close to the original material, which is a plain record of points with no scale. I left out any numbers, because the values are only relative heights read back from a small picture.
