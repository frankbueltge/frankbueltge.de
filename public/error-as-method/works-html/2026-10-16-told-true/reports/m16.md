I made "Solar Time, Moon Lines" (`/tmp/claude-0/s130/mk/m16/work/index.html`, with `/tmp/claude-0/s130/mk/m16/work/NOTE.md`). It is a single still SVG, 1100×800, with the data written into the page and nothing loaded from elsewhere. I checked it by rendering it in headless Chromium. The main thing to know: I don't think this record is a tide.

**What I did first with the file.** I read the pixels. The dots run from x = 2 to x = 297, so each pixel column holds about 4.9 hours. The dark ink comes to about 0.8 pixels per value, so the dots are tiny. Before drawing anything I measured the record: the average dot height in each column, a periodogram of that series, and a 24-hour fit in a window sliding along the record.

**How I got to the form.**
- **Recovering the values:** I split each column's ink into as many equal shares as there are hours in that column, which gives each column's set of values. The picture can't show what order those values came in within a column. I set the order using a smooth model fitted to the data: a slowly moving mean plus a 24-hour cycle. That ordering covers about 5 hours at most, so the hourly detail in the work is partly reconstructed, not read directly. The day-scale pattern does not depend on it.
- **The form:** it is a double-plotted actogram, the chart biologists use to check whether a rhythm keeps to the clock. There are 61 rows; each row shows one day and the next, with each hour as a tile shaded by its value.
- **Red strokes** rise from the few hours that go past the darkest shade; their length shows how far past.
- **Blue diagonal lines** mark where the high waters of a normal moon-driven tide would fall, 50 minutes later each day. The data does not follow them: its dark bands stand straight up for all two months.

**My view of what was measured.** I think it is something driven by the sun's daily cycle, most likely air temperature or shallow-water temperature, and not harbour water level. It rests on four things in the file:
1. **No twice-daily tide.** There is no measurable cycle near 12.42 hours, the period of the main moon-driven tide. Within each 5-hour column the values sit close together (median spread about 3 px), so nothing large is swinging up and down within a few hours.
2. **One strong 24-hour cycle,** with an amplitude of about 9 px against a band about 35 px tall.
3. **It keeps steady time.** The cycle's size stays between about 7 and 13 px all the way through. A once-daily tide would swell and nearly vanish every 13.7 days and drift by about 50 minutes a day against clock time. Here the timing drifts by only about 2 hours over the whole record, which is within what my pixel-to-hour conversion could produce.
4. **Highs only at the daily peak.** The highest values, including a few single-hour spikes, all fall within about 3 hours of each day's peak and never at the low point. That fits a sensor catching direct sun at midday; it doesn't fit a glitch in a water-level gauge.

There are also slow swings of several days in the average level, around days 8–28 and days 29–35, which look like weather.

**Things the commissioner should know.**
- The work's own caption calls it "a harbour record", because that is what I was told. The second caption line and the blue lines then show why the data doesn't behave like one. If the label is right, the gauge is somewhere with almost no moon tide and a strong daily signal, which would be unusual.
- The day numbers and hour labels count from the start of the record, not from local midnight, because no clock time was given.
