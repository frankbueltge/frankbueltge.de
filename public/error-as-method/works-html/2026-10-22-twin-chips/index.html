Twin Chips

Each pair is one colour, twice. The left chip is a point where a crowd of colour-survey takers put a name. The right one is moved two to four units in each channel, too little for an eye to see. Twelve machine makers named them: six read only the hex numbers, six only looked at a picture. Under each chip are the names the number-readers gave. A name in bold is the crowd's own.

Crowd names and points: the xkcd colour survey's list of 949 colours (R. Munroe, 2010, CC0), xkcd.com/color/rgb.txt. Each point is where answers for that name were densest. It is not what most people call that point, so a bold name here is a match with the crowd's map, not with "the right answer". Chips drawn by seed 151. The twin rule, the briefs, every maker's reply and the scoring are in this experiment's directory. Experiment 35 of the error line's project, Session 151.
