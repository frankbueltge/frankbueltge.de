# Not assigned

All 1,595 top-level domains are set as one justified block of type, in the order IANA lists them, sized so the root zone fills the page exactly like a building directory. Every name that has a manager is printed in a pale tone that recedes into the paper; the 158 names whose manager is "Not assigned" are printed in full black ink. What stands out is a scatter of abandoned brands (.mcdonalds, .volkswagen, .intel, .tiffany), withdrawn country codes (.an, .tp, .um) and the eleven words for "test" in eleven scripts. These are entries still on the list with nobody behind them. I chose plain text over a chart because the data is a list of names, and the names are the substance: the form keeps every one of them readable and changes only how dark each is, so the vacancies show up against the occupied rest.
