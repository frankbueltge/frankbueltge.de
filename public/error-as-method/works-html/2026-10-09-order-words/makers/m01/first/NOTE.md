# Not Assigned

The whole root zone is set as one justified page of type, all 1,595 top-level domains in the order the registry lists them, sized so the full list just fills the frame. Country codes are set heavy, so the 316 places show as dark grains in a pale field of generic names. The 158 domains that are still in the database but listed as "Not assigned" (mostly brand names that were bought and then given up, such as .chrysler, .intel, .mcdonalds, .tiffany) are drawn only in thin red outline. They aren't removed: they still take up their place in the line, but nothing fills them in. I chose a page of text over a chart because the material is a list of names, and the thing worth seeing is how many of those names are now empty claims scattered all through the alphabet.
