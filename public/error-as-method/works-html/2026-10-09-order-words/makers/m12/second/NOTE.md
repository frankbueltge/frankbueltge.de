# Vacancies

All 1,595 top-level domains in the root zone are set in their registry order as one justified block of text, like a page from a ledger. Type sizes itself so that the whole zone fits on one sheet. The 158 names whose manager is listed as "Not assigned" are shaded and set in red. Most of these are brand domains such as .abarth, .chrysler and .northwesternmutual that were applied for and later left; the rest are the test names that were never meant to be held. I picked a typeset page over a chart because the material is a list of names, and its most telling feature is where that list is empty. Reading straight through, you see the vacancies scattered through the alphabet, and they read as places where something was paid for, given a name and then walked away from.
