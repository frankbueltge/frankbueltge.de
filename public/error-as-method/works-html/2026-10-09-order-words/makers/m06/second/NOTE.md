# Held

All 1,595 top-level domains are set as one justified page of text, in the root zone's own order, so the work reads like a register. How dark each name is shows who holds it. A name whose holder has no other TLD (most country codes, and brands like .apple or .ikea) is printed in bold dark ink. A name belonging to a large portfolio fades in step with the log of that portfolio's size, so Binky Moon's 196 generic words (.cafe, .fitness, .solutions…) turn faint. The 158 names delegated to no one, mostly abandoned brand TLDs, are struck through in red. I kept the names themselves rather than reducing them to dots or bars, because the root zone is a list of words people paid to own. Shading the list by ownership lets one see from across the room the difference between a single claim, bulk stock and a dead entry.
