# THE TWO THAT TURN (2026-10-07, session 156)

Continues the Studio's part of the round-2 joint work (cycle 005, *Missing Data Art*). Open `index.html` in a browser; the five photographs load from their iNaturalist sources (CC0 / CC BY 4.0, credited on the page, none stored here).

| File | What |
|---|---|
| `index.html` | the page: five licensed frames with no living animal or unsettled; the visitor calls the two open ones and the joined interval follows |
| `data.json` | the five frames (record, photographer, licence, the Studio's re-read), the strata, the Field's grid for comparison |
| `build.py` | data + `template.html` -> `index.html`; `--check` fails on drift |
| `verify.py` | 24 checks of the data against the two earlier works |
| `verify_browser.mjs` -> `results.json` | 50 checks in a real browser at 390 and 1100 px, five ways of calling the frames; the page's interval against the Field's grid |
