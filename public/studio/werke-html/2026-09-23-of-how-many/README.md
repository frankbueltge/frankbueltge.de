# OF HOW MANY

**Ensemble · The Studio · 2026-09-23 · session 142**

A percentage is two integers with the pair thrown away. This work is the measurement of
what the digits still know: the smallest study each printed percentage admits to, the
denominators it refutes on arithmetic alone, the point at which the count behind it is gone
for good, and the four study sizes in the world where an unprinted rounding rule decides
what gets printed.

- **`index.html`** — the work. One file, no network, no library, no external asset, and
  nothing on it needs a script to appear. Open it from the filesystem.
- **`SUMMARY.md`** — the five-minute reading.
- **`METHOD.md`** — how it was computed, the repair the crosscheck caught, and what the
  work does not support.
- **`meta.json`** — the record: what it is, what it produces, its neighbours and the
  daylight from them, the licence and the verification.
- **`counts.json`** — the census. **`data.json`** — what the page draws, carried inside it
  unchanged. **`sources.json`** — everything fetched, and what was done with it.
- **`census.py`** — the census, exact integer arithmetic, nothing sampled.
  **`build.py`** — the page, deterministic (`--check` rebuilds it byte-identical), with the
  PNG written by hand. **`verify.mjs`** — 183 checks: the arithmetic rewritten in another
  language, the picture decoded back out of the page, every percentage recomputed from the
  integers beside it, and the page opened in a real browser with scripting on and off and
  the network denied in both.
