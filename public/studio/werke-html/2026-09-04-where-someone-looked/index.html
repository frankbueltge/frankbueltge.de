WHERE SOMEONE LOOKED

The house's Atlas of Data Art holds 521 works, and its timeline looks like a history of the field. It is not one. 317 of the 521 are cited from three addresses; the other 204 come from 160. Ask the same file a different question — which entries has anyone checked? — and the answer is almost the same two hundred works: 191 of them in both sets, and 25 cells that move.

The counter-reading, stated because it is the fair one: an entry taken from a trusted inventory may need no separate checking — the trust is placed in the list once, and the entries inherit it. That is a defensible way to build a catalogue. It is also exactly what this practice measured on the day before this page was made: 56 of the 188 entries cited from artbase.rhizome.org carry scraped catalogue page furniture in their decisive_move field — inception: 2007 outside link Description description edit — rather than a sentence about the work. Trust transferred to a list arrives at the entry, and at the entry it can be wrong. Every one of the 56 is already flagged toVerify in the file, so the house's own column is doing its work; nothing here is a defect the catalogue hides.

A number of ours that did not reproduce, left standing. The record of 2026-09-03 reported 61 such entries and published the rule that finds them. Run against today's feed, that same published rule returns 56. The citation set is identical in all 503 addresses across the two days, so the entries did not move: the difference is in the rule, not in the file. Yesterday's number stands under its date and is not withdrawn; today's is derived beside it, in evidence/recheck.json.

Not an accusation

The Atlas is months old, it is published whole, and it carries a column that says which of its entries have been checked. That is why this reading was possible at all: a catalogue that publishes its own uncertainty can be read against itself, and one that does not, cannot. Every catalogue has the shape found here — the reachable inventory gives most of the entries, and the years no inventory covers are remembered thinly. What this page adds is that in this file the shape is measurable in two independent columns that were never written to agree, and they agree at 88.4 per cent. Whether an entry from an inventory ought to be checked one by one is the house's decision and not this room's; nothing here says anyone did anything wrong.

Form, on the merits. Interactive and client-rendered, because the object is a difference of 25 cells out of 521 between two questions, and superposition — the same wall repainted in place — is the only honest way to show a difference that small. Two still pictures side by side would ask a reader to compare 521 cells across a page by eye. The floor without JavaScript is not a lesser version of the same picture but the other complete one: all four classes painted at once, every count printed, and all 42 year records standing open. Both are drawn from one markup — each cell carries its own classes and the control only changes which are lit — so the two states cannot disagree about a single work. All motion is user-driven; reduced motion is honoured.
