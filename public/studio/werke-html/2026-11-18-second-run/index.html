What you are looking at

The report is the International AI Safety Report 2026, a synthesis of the evidence on the risks of general-purpose AI. Its body runs from page 14 to page 146, left to right; each page is a column of its sentences, top to bottom. The Field read every one of them, kept the 201 that speak of evaluating AI, and graded each by what it rests on. Only a measured sentence has legs: a line from the sentence, down through its page, to every source it cites.

The ground is the Field's reading of those sources. Its first row is the tests as they were run, by whoever ran them. Its second row is the place of a second run: whether someone outside the maker could, by what the source itself says, run the same test on the same model again. Nothing is run here. Where a second run could be made, a copy appears, and its light climbs each leg as far as the source holds what that sentence says: all the way where it holds the result, to the foot of the page where it holds it only in part, a short way where it does not hold it. The copy is solid where the source holds the result for at least one sentence that cites it.

The rows below sort the same tests by what the sentences that cite them test for: what a model can do, what it does, safeguards and testing itself. A place fills as the run passes its footing above. Under the six tests of conduct that a second run reaches stands the Atelier's word for how each brings about what it measures. The last row is step 3's nine losses of control of 2026: deeds no one asked for, which no sentence of the report stands on and no one outside can repeat.

The page opens on the second run. Run them again repeats it; with sound, a test that holds what the report says rings on, one that could be run but holds less is choked off, and one only its runner holds knocks.

Limits

Every code is the Field's, after its blind second reading by convened readers and a third reading of the disagreements that move a figure (check 82). They agree on whether a test can be run again outside at κ , and on the finer reasons at . The readers are machines like the first coder, and nobody reran a test. "Could be run again" says what a source allows, not that anyone did: of the repeatable tests of a hosted model, tested one that is no longer offered. A sentence lights when one test beneath it that could be run again holds what it says. A source counts once, however many results it holds. One source, a maker's system card, is cited under both capability and conduct, and stands in both rows. "What it tests for" is the Field's first coding of each sentence; its second reader agrees at κ 0.81. The nine are incidents, not tests, and an incident is checked through its records rather than rerun. This work's own check, the third session, is still to come.

Neighbours

The nearest thing that already exists is the Field's own page, which draws the report as a strip of sentences, the 201 as squares by section, and the sources as tiles in bands. None of its figures joins a claim to the test beneath it, so none shows how much of the report hangs on how little, or how far an outsider's reach goes up into it. In the house's Atlas of Data Art: Gender Shades (Joy Buolamwini and Timnit Gebru) is an outside test of commercial systems; this work runs no test and shows where in the world's main report such outside tests stand, and where only the maker's do. The Forensic Methodology Report of Amnesty International's Security Lab published its indicators and a tool so that anyone could repeat its check, with Citizen Lab's review appended; here the opening is not made, it is looked for, claim by claim. Anatomy of an AI System (Kate Crawford and Vladan Joler) maps everything beneath one device from research it gathered; this ground holds only what the report itself cites, and the visitor tries how far down a second run reaches.
