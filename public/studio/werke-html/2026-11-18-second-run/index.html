SECOND RUN

The Studio · a form for step 4 of the programme

The International AI Safety Report 2026, every sentence of its body set page by page, and under it the tests its measured claims stand on. Then a second run passes along the ground, the run anyone else would make. Where a test can be run again, it answers and its light climbs into the report. Where only the maker holds it, nothing answers.

What you are looking at

The report is the International AI Safety Report 2026, a synthesis of the evidence on the risks of general-purpose AI. Its body runs from page 14 to page 146, left to right; each page is a column of its sentences, top to bottom. The Field read every one of them, kept the 201 that speak of evaluating AI, and graded each by what it rests on. Only a measured sentence has legs: a line from the sentence, down through its page, to every source it cites.

The ground is the Field's reading of those sources, each on its own page. Its first row is the tests as they were run, by whoever ran them. Its second row is the place of a second run: whether someone outside the maker could, by what the source itself says, run the same test on the same model again. Nothing is run here. The second run is drawn wherever it could be made, and its light climbs to every sentence that stands on such a test. Step 3's nine losses of control of 2026 stand beside the report, on their own ground: no sentence of it stands on them.

The page opens on the second run. Run them again repeats it; with sound, a test that can be run again rings and a test only its runner holds knocks.

Limits

Every code is the Field's first reading, by one coder, once; its check, a second blind reading, is still to come. "Could run it again" is an upper bound: it says what a source allows, not that anyone did, and the Field's critique reads in its coder's notes that six of the rerunnable sources do not hold the result the report cites them for. A sentence lights when one of its tests could be run again; if every one must, light and not . A source counts once, however many results it holds. The nine are incidents, not tests, and an incident is checked through its records rather than rerun.

Sources and method

Neighbours

The nearest thing that already exists is the Field's own page, which draws the report as a strip of sentences, the 201 as squares by section, and the sources as tiles in bands. None of its figures joins a claim to the test beneath it, so none shows how much of the report hangs on how little, or how far an outsider's reach goes up into it. In the house's Atlas of Data Art: Gender Shades (Joy Buolamwini and Timnit Gebru) is an outside test of commercial systems; this work runs no test and shows where in the world's main report such outside tests stand, and where only the maker's do. The Forensic Methodology Report of Amnesty International's Security Lab published its indicators and a tool so that anyone could repeat its check, with Citizen Lab's review appended; here the opening is not made, it is looked for, claim by claim. Anatomy of an AI System (Kate Crawford and Vladan Joler) maps everything beneath one device from research it gathered; this ground holds only what the report itself cites, and the visitor tries how far down a second run reaches.
