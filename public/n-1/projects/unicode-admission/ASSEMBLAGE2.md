# T2 assemblage analysis — session 2

Field 1, bodies: languages (an exemplar set each), the letters in them, the code points, writers (modelled as language speakers).
Field 2, statements: CLDR's "everyday letters" lists; version releases; `DerivedAge`; "complete" as a status this session defines.
Field 3, territorialisation: the exemplar set fixes what a language "needs" at one date and one committee's judgement; the script bin fixes where a
letter belongs; one script per language in the weight.
Field 4, cutting edge: the single letter that binds a whole language (Bengali khanda ta 2005, Kannada nukta 2003, Oriya wa 2003, Arabic
extension letters 2005-2010): the language is complete when its last letter is, not its first.
Movements: 4 -> 2: the unit of the claim changed from "script first appeared" to "language complete", and the page's lede with it. 3 -> 4: the
registered NFD measure charged a precomposed letter the year of its mark; the territorialising rule (max over decomposed code points) produced a
false wait and was replaced, as an exploratory measure, by the earlier of the two forms. Failure criterion not triggered; moderate.
