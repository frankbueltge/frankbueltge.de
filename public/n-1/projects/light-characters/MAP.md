# Project 10 — mapping protocol (T1)

*A map of the project as an assemblage: lines, not positions (ATP 8-9, via KsK T1). Each version dated; versions stand, the map grows.*

## Version 1 — 2026-10-16 19:57 UTC (first written as 19:58, ahead of the clock; corrected) (session 1, written after the page was first built)

Stated first, because the failure criterion asks it: this version was written after the registered run, the reading and the first
build, not before them. It is a first map, not a record of the session's decisions.

**Elements (all registers on one sheet).** The lights (42,501 records; 32,777 rhythmic with a position). The list (NGA Pub. 110-116,
weekly corrections). The rule (IALA's sentence: same character outside each nominal range). Keepers, authorities, mariners — named
by the list's remarks only ("Private light", "Synchronized with front"). The code (`Fl.(2)W. 10s`: pattern, colour, period). The
lateral convention (colour says the side). Regional habits (entry 5 of `REFRAIN.md`). The practice's parser, shuffle, page.

**Lines that operate.**
- rule → list: a *should*, not a constraint the list obeys measurably (`session1.json`, `explore1.json`).
- lateral convention → small lights: rhythm shared on purpose; the small lights' repeats are grammar (`verify.json`, 5 of 20 pairs).
- leading line → pair: front and rear repeat each other by design; a repeat that *is* the signal (3 of 20 pairs).
- coast → key: each coast keeps its periods; the shuffle that ignored this inverted the result (R < 1).
- list → page: 624 great lights within reach of their own rhythm, drawn as lines.

**Segmentations.** Volume boundaries (the shuffle's strata); range classes (15 and 8 nm, chosen before); fixed vs rhythmic (fixed
lights fall out of the question entirely); the period field (5,344 entries without one fall out).

**Copies laid back.** The blinking world map of lighthouses (neighbour, `NEIGHBOURS.md`) — the page blinks only the chosen pair, never
the map. IALA's rule — laid on the list as a question, not as a verdict on any light.

**Dead ends entered.** xeno-canto (a key) and GBIF (reset): the first candidate. The first null (volume-wide shuffle): it measured the
coast's habits, not the lights' spacing.

**What the map shows that the page does not.** Two lines cross nowhere on the page: *range* (paper reach) and *sector* (the arcs in
which a light is shown). Of the 20 read pairs, 3 were sector lights or bridge faces whose beams need not meet. A repeat within range
whose arcs do not overlap is not a repeat a sailor sees. **Decision taken from this version:** session 2's question, if the data
asks for it, is the arcs — whether the 624 great repeats survive the visibility sectors the list gives in its remarks. Not decided
before this map was drawn; the counterfactual (an estimate) is that session 2 would have taken the United States' own list as more
material, a widening instead of a sharpening.
