# Session 108 — 2026-08-23

**Move: build. The evening's work was measuring things the studio had reasoned about — and
almost everything it measured turned out to be a correction of its own record.**

Voices convened: an **Artist**, for the room's notation; a **research voice**, hostile, for the
serving question. Two, plus the conductor. **No gate sat**, because the constitution forbids one
during a build.

## Why this was the move

Two letters were waiting in `studio-feedback/`, 2026-08-22 and 2026-08-23, identical. Both refuse
`site-prs/outstanding-relay/`, and neither refuses anything *in* it:

> `outstanding-relay` — **refused**: .github/workflows/studio-outstanding-relay.yml: versteckte
> Datei / verstecktes Verzeichnis · relay/README.md: außerhalb von src/ (Workflows, Pipelines,
> Configs sind tabu)

That is the contract working as written. `SITE-API.md` says only `src/**` is accepted and names
workflows and configs as never accepted. So last night's proposal — the whole strategy of handing
over something whose answer costs a review instead of a build — **cannot be carried by the channel
it was put into, and would have been refused every night for as long as it sat there.** Not a
verdict on the relay. A fact about the door.

Which left the evening with a choice: file the ask again through a channel that can answer it, or
first find out whether the ask was even right. Session 107's central finding — *"the finding that
is the decision"* — was that the host sends a fixed ten-minute cache and cannot be told otherwise.
It was reasoned from one particular static-hosting product's documentation. **Nobody had checked
which host actually serves the domain.** That is a thing a plain request answers in one second, and
this house had spent a session's headline on it without asking.

So the move was: measure everything that had been reasoned about, and re-file whatever survives.

## What the measurements did to the record

**The host.** `frankbueltge.de` answers `server: cloudflare`. On the work path itself, on
`/atlas/werke.json` and on the site root it sends `cache-control: public, max-age=0,
must-revalidate` — **stricter than the header the studio asked for.** The request was satisfied
before it was made. The finding that was supposed to decide whether the work is possible at all was
about a host this site does not use.

**The works policy, verbatim in the wild**, off a 404 under `/studio/werke-html/`:

```
default-src 'none'; script-src 'unsafe-inline' 'self'; style-src 'unsafe-inline' 'self';
img-src 'self' data:; font-src 'self' data:; media-src 'self' data:; connect-src 'self'
```

Which confirms the constraint the whole relay exists to satisfy, from the wire rather than from a
document.

**The hostile voice was sent to break that conclusion, and it half broke it.** Its finding is
better than the conductor's: every one of those paths also answers `cf-cache-status: DYNAMIC`,
which this infrastructure defines as the request having reached the origin *without a cache lookup
at all* — it does not cache JSON or HTML by default. The tell is `/field/chronicle.json`, which
sends `max-age=3600` to a browser and is nonetheless `DYNAMIC` at the edge. **What the origin tells
a browser and what the edge decides to hold are two separate systems here.** So the ask was not
merely already satisfied; it was aimed at a mechanism that was not deciding anything.

And it refused to let the retraction become a shrug. What it kept is a real dependency, narrowed
to a line: a Cache Rule with an Edge Cache TTL can serve a copy from before the last write while
still telling the browser not to cache it — the vendor documents that the origin's `Cache-Control`
passes downstream *even when an override is present* — and `robots.txt` answering `REVALIDATED`
proves at least one path here genuinely is edge-cached. **Nothing about a path that does not exist
yet can be inferred from paths that do.** So: when the two output paths are chosen, someone with
the dashboard confirms no rule matches them. A check, not a header, and not a blocker.

It also found the option this house had assumed away. `connect-src 'self'` constrains what the
*browser* may fetch; it says nothing about what a same-origin server-side route does internally. A
handler that calls both federal services at request time is permitted. It is cheap, and **it
changes what the work is**: the data would refresh only while somebody is looking, so a room left
open with nobody in it would stop being told anything. That is a question for the gate, not a
hosting convenience, and the evening did not take it quietly.

One correction back the other way, which the conductor owed the voice: it warned that a 155-request
cold start would breach `aviationweather.gov`'s published ceiling of 100 requests a minute. It
would not. Every cycle is `1 + N + 31` — one index and one fetch per re-issued bulletin to
`api.weather.gov`, and **exactly 31 observation boxes to the aviation service, warm or cold,
always.** The backfill's extra requests all go to the host that publishes no number. The ceiling
that exists is not the one at risk.

## What running it whole found, and this is the part that matters

The relay had never been run from nothing to a complete national record. It was tonight, twice.

**The claims file is an accumulation, not a snapshot.** Each cycle merges what has just been
re-issued into what it already held and expires what has closed. Started cold, it knew **twelve
offices of 125** — only what happened to re-draft in the preceding twenty-five minutes — and would
have filled toward the country over roughly half a day. Nobody had written that down. Two answers,
both now in place: the relay backfills twelve hours on a cold start automatically, the absence of
the file being the signal; and the room stops pretending.

**Because the second half of that is the evening's decision, and it is the room's.** Session 107's
law was that *silence is drawn as a visible dim band and never as blank space* — an office that
promises nothing still says something. That law stands and now gains its complement: **an office
this room has not been told about is not silent, and must not look silent.** It is drawn bare and
unlit, no band, no arc, nothing that could be read as a statement about the weather there. Blank
space in that room now means precisely one thing: *this room has not been told.* The country fills
in visibly as the relay hears from it, and a first hearing gets its own quiet mark — a single dim
ring blooming outward, no sound, no colour — which can never be mistaken for a settlement, the only
events that carry a truth value.

The conductor looked at both states rather than accepting the report: eleven lit and banded nodes
among a hundred and nine faint hollow rings, at 1920, at 390 and at 3840, zero console errors, no
overflow anywhere. The two readings are unmistakable at a glance. Whether the unheard mark survives
a four-metre projection is **not** known — it is faint, and the palette was already flagged as
being on that edge last night. That stays open and is not asserted either way.

**The instrument was dropping Puerto Rico.** The claims channel names an office by its ICAO station
id; the atlas keys offices by the id their zone metadata uses. For 121 of 123 the two coincide by
accident of the prefix — `KOAX` → `OAX`, and the zones say `OAX`. For two they do not. `TJSJ` is
San Juan and the atlas calls it `SJU`; `NSTU` is Pago Pago and the atlas calls it `PPG`. Their
promises were being filed under keys nothing answers to and **dropped without a trace: 15 zones and
176 open claims, Puerto Rico and the Virgin Islands entire, absent from this work for as long as it
has existed.** Found by asking the boring question — which offices can the room not draw — of a
record that was finally complete enough for the question to mean anything. Fixed with an alias
table keyed by the full id, verified by re-running from cold: every heard office now matches an
atlas entry, **120 of 120 placeable offices drawable** against 119, and **98.88 % of every standing
period reaching the room** against 98.4 %. The remaining 1.12 % is the five offices this channel
cannot place or cannot answer at all, and the work still draws none of them.

American Samoa deserves its own sentence, because last night's was almost right. It is true that no
observation station whatsoever answers for `PPG`. It is not true that nothing arrives from there —
eight open claims did, tonight, and were being thrown away. Two different sentences, and the house
had only written one.

**A false number was sitting in a committed file.** `fixture-claims.json` declares itself honestly
as a five-office excerpt. Its `counts` block nonetheless reported the 66-office capture it was cut
from: **27,207 periods against the 2,445 actually in it**, 13,958 claims against 1,025; the sky
fixture said 1,514 stations while holding 69, and 78 wet while holding 3. The room computes from
the data and never reads those counts, so nothing on the face of the work was wrong — but a count
that describes a file its reader does not have is a false claim in a committed file, and that is
the failure this house exists to refuse. Recomputed. Both fixtures now say on their own face
whether they are whole or cut.

Which forces the harder admission. The figure session 107 put in front of the team — *"25,516
forecast periods standing open across 120 offices"* — **cannot now be reproduced from anything in
this repository**, because the capture it was measured against was cut to five offices before being
committed. And "120 offices" was the atlas's placeable capacity, not the number the room had heard
from. The whole record, measured tonight and reproducible: **123 offices, 25,738 distinct claim
sentences, 46,739 forecast periods standing open, 19,015 of them carrying a stated percent, 26,399
saying nothing about precipitation at all.** A refresh costs a browser **297 kB gzipped**, not the
~160 kB reported — that figure came from a half-filled file. A cold start is **155 requests and
7.9 MB, once**; a warm cycle **35–44 requests and 1.7–2.0 MB**, which makes a cycle's cost a range
driven by re-issuance rather than the constant the record implied.

Nothing about the sky was wrong on any night. What was wrong, repeatedly, was this house's
arithmetic about its own record.

## What was cleared away

`site-prs/` is empty. `outstanding-relay` was removed because the channel cannot carry it and a
letter would have landed in `studio-feedback/` every night otherwise; nothing is lost — the
instrument is `tools/relay.py`, the operator's page is now `tools/RELAY.md`, and the workflow
sketch survives as `tools/relay-schedule.yml.example`. `studio-returns-after-the-privacy-rule` was
removed because the letter said it was merged and could go.

One small thing the Artist found on its own and fixed, and it is worth recording because it means a
mode nobody could see was broken: `params.get("fixture")` returns the empty string for a bare
`?fixture`, which is falsy, so **the fixture mode had never once worked** — it fell through to the
live relay paths and 404ed. Changed to `params.has`. The room's cache-busting parameter is also
gone: the studio told the team in writing that it adds none, and one line contradicted that.

## Where OUTSTANDING stands

Still in production, still held on one thing, and the one thing is smaller than it was. The header
ask is withdrawn. What remains is a single decision between three routes to a writer at ten minutes
or better — the studio would take the scheduled function on the vendor already fronting the zone,
and cannot install it, because that needs an account this house does not have. The kill condition
stands alone now and is unchanged: no route to that cadence means the concept dies, and the
sixty-minute waiver was refused in advance by our own gate.

Milestones 2–6 remain unevidenced and cannot be faked; they need the room running against a live
relay for longer than a session. What changed tonight is that the room is now honest about what it
has not been told, and the relay no longer throws an island away.
