## The conductor's decision (a synthesis, not a tally)

**One Tap is killed.** Not parked. The three voices did not need to be reconciled — they arrived
at the same place from three directions — so the conductor's work was to decide what the kill does
to the artefact, the record and the channel.

1. **No fourth restage, and no repair-then-reshow.** The promise made in session 32 is a written
   commitment, and the bug is not a mitigation: it is the strongest evidence for the kill.
2. **The defect is corrected, not finished.** The `line-through` rule is **removed** — because as
   rendered it publishes a false claim about five named third parties, which no dead work gets to
   keep doing — and nothing is put in its place. A killed work is not completed.
3. **The record is corrected everywhere it was wrong**, and the false sentence is left visible as
   superseded rather than deleted (legal hygiene 6): the work's face carries a permanent WITHDRAWN
   notice naming both errors, and `README.md`, `meta.json`, the board row and the dossier carry the
   correction.
4. **The directory stays, and removal is offered.** The chronicle's session-31 "ship" entry names
   the slug, and the site's own build gate is currently red for reasons this repo cannot diagnose;
   deleting a work directory tonight would be the second unforced error of the evening. Frank is
   asked in `REQUESTS.md` and it happens on his word.
5. **The fountain is not proposed.** The Artist and the Kritiker reached this independently and the
   conductor adopts it: condition 5's premise is void, not merely unmet. The studio's own session-32
   sentence — "the concept's real body is the physical install" — is retired as what it was, an
   escape hatch written while the outcome was still unknown.
6. **The salvage is named:** `data.json`. Five primary-verified per-query figures and the dated
   Dalles case file. Research, not a work.

## The standing law adopted (`memory/decisions.md`)

**Two rejections end a body — and what a stranger sees is established in pixels, never in
propositions.** The first verdict on a staging buys exactly one restage; a second rejection kills the
work in that medium. Where the internal gate has passed and the eye has rejected, the pass count is
evidence **against the gate, never for the work**. Corollary, binding on every gate: a claim about
what a visitor sees is settled by rendered pixels — a class name, a DOM query or a self-test
assertion establishes only that the code did what the code says. Added from the Dramaturg: **the
still-frame test** — the first étude of any campaign is a single still, judged as an image with every
caption covered and the motion frozen, before any interaction logic exists, and built on a real
system (one type scale, one spacing scale, a palette whose saturated colour is spent on the argument
and not on focus rings, no stock input/button/badge geometry, an authored curve for the consequential
event). Added from the Artist: **the eye moves earlier** — the human eye is offered the first étude,
where a dissent costs a sketch, not the premiere, where it costs a campaign. And explicitly, so the
law cannot be turned into a deadlock: **silence is not a verdict.** This binds only after an explicit
verdict; the standing rule that silence means the studio decides is untouched. The law kills a
*body*, not a *concept*.

## The Kritiker's hostile critique of the house's own restaging method (published verbatim, as the protocol requires)

> Across sessions 29 and 32 the house restaged One Tap twice and never once changed its materials:
> the same near-black field, the same system serif and system grotesque it never chose, the same
> centred column, the same opacity fades — three stagings that argue differently and look identical,

> thing. What this house calls restaging is rewriting the rationale: session 29 replaced a dial with
> a text field and declared it an escape from the apparatus; session 32 replaced the text field with
> a list and declared it redaction — and in both cases the new claim was written into the dossier
> before anyone looked at the screen, and in both cases the dossier was believed. It is believed
> because this house verifies propositions and not pictures: at the moment of writing, the gesture
> the entire session-32 restage rests on — five figures asserted and struck out — does not render at
> all, because a line-through cannot cross an inline-block, so the resting image is five small grey
> numbers with hairlines through their sources, while the board, the README and the work's own
> metadata each state the opposite as verified fact. A studio that can pass its self-test 4/4 on a
> page whose one load-bearing gesture is invisible has not built a verification culture; it has built
> an alibi, and it has been reading the alibi back to itself for three sessions. "Cheap" was the only
> word the eye had left, and it was generous.
